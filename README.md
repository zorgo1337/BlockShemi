# 🔄 CodeFlow Visualizer

> Автоматический генератор блок-схем по исходному коду.

## 📖 Описание
**CodeFlow Visualizer** — это инструмент, который анализирует исходный код и автоматически строит по нему наглядную блок-схему алгоритма. Программа парсит основные программные конструкции: присваивания, условные операторы (`if/else`), циклы (`for`, `while`) и операции ввода/вывода, превращая их в понятный визуальный граф.

Инструмент идеально подходит для студентов, преподавателей и разработчиков, которым необходимо быстро документировать логику работы кода, проверять алгоритмы или готовить материалы для технической документации.

## ✨ Возможности
- 📂 **Загрузка кода:** Импорт файлов с исходным кодом (`.cs`, `.py`, `.txt`).
- 🧠 **Анализ логики:** Распознавание вложенных циклов, условий и последовательных операций.
- 🎨 **Стандартная визуализация:** Цветовое кодирование блоков по ГОСТ/стандарту (овалы для начала/конца, ромбы для условий, параллелограммы для ввода/вывода, прямоугольники для процессов).
- 💾 **Экспорт данных:** Сохранение результата в формате `.png` (изображение) или `.drawio` (для дальнейшего редактирования в draw.io).
- 📊 **Статистика:** Подсчет количества блоков и связей в реальном времени.

## 🚀 Быстрый старт
1. Скачайте или склонируйте репозиторий с проектом.
2. Запустите приложение (`CodeFlowVisualizer.exe` или `python main.py`).
3. Нажмите кнопку **"Загрузить файл"** и выберите файл с исходным кодом.
4. Нажмите **"Построить блок-схему"**.
5. При необходимости экспортируйте результат через кнопки панели инструментов.

## 🛠️ Технологический стек
- **Язык реализации:** C# (.NET) / Python *(выберите нужное)*
- **Интерфейс:** Windows Forms / WPF / Web (HTML5 + JS)
- **Рендеринг графов:** Graphviz / Mermaid.js / Кастомный SVG-рендерер
